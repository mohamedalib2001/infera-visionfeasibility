🎯 الهدف النهائي
━━━━━━━━━━━━━━━━━━━━━━
إعادة بناء مخرجات منصة دراسات الجدوى بالكامل لتكون:
- دراسة جدوى احترافية قابلة للتقديم إلى:
  • بنوك
  • صناديق استثمار
  • مستثمرين ملائكيين
  • جهات تمويل حكومية
- وثيقة تنفيذية Executive-Grade
- جذابة بصريًا
- دقيقة ماليًا
- منضبطة لغويًا
- مبنية على السوق والموقع الحقيقيين

━━━━━━━━━━━━━━━━━━━━━━
🧱 إلزاميات هيكل التقرير (MANDATORY)
━━━━━━━━━━━━━━━━━━━━━━
يجب أن يلتزم كل تقرير بالهيكل التالي حرفيًا:

1️⃣ صفحة غلاف احترافية
- اسم المشروع
- القطاع
- الدولة / المدينة
- تاريخ الإصدار
- مدة الدراسة
- شعار المنصة

2️⃣ ملخص تنفيذي (Executive Summary)
- قرار الاستثمار (GO / NO-GO)
- حجم الاستثمار
- العائد المتوقع
- المخاطر الجوهرية
- سبب التوصية في 5 نقاط مختصرة

3️⃣ تحليل السوق (Market Analysis)
- حجم السوق TAM / SAM / SOM
- السوق المستهدف حسب الموقع الجغرافي
- شرائح العملاء (Personas)
- تحليل المنافسين (جدول + مقارنة)
- اتجاهات السوق مدعومة بأرقام

4️⃣ التحليل الفني والتشغيلي
- نموذج التشغيل
- الطاقة الإنتاجية
- سلسلة التوريد
- الموارد البشرية
- التكنولوجيا والمعدات

5️⃣ التحليل المالي (Financial Analysis)
- CAPEX
- OPEX
- الإيرادات المتوقعة
- التدفقات النقدية (5 سنوات)
- IRR / NPV / ROI / Payback Period
- 3 سيناريوهات: متحفظ / أساسي / متفائل

6️⃣ الرسوم البيانية (إلزامي)
- مخطط نمو الإيرادات
- مخطط التكاليف
- مخطط التدفقات النقدية
- مخطط توزيع المخاطر
❌ أي قسم مالي بدون Charts = مرفوض

7️⃣ تحليل المخاطر
- مصفوفة مخاطر (Probability × Impact)
- تصنيف: مالية / تشغيلية / سوقية / تنظيمية
- خطة تخفيف لكل خطر

8️⃣ التوصيات وخارطة التنفيذ
- خطوات 90 يوم
- متطلبات التمويل
- مؤشرات الأداء KPI
- شروط النجاح

9️⃣ الخلاصة النهائية
- توصية واضحة
- منطق استثماري مقنع
- لغة حازمة غير مترددة

🖋️ إلزاميات اللغة العربية
━━━━━━━━━━━━━━━━━━━━━━
- اتجاه RTL كامل (نص + جداول + عناوين)
- لغة عربية رسمية احترافية (لغة تقارير أعمال)
- فقرات قصيرة، واضحة، متوازنة
- عناوين قوية
- لا توجد جمل طويلة أو متداخلة
- لا يوجد "كلام عام"

🎨 إلزاميات العرض البصري

- كل قسم داخل Card واضحة
- فواصل بصرية بين الصفحات
- ألوان متناسقة
- أيقونات خفيفة
- جداول منظمة
- لا يوجد تكدس نصوص
